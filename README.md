# cloud-control-plane-web

React console for the [Cloud Control Plane](../cloud-control-plane) project.

**Not built yet.** This is a placeholder repo reserved for Phase 1.4 of
`cloud-control-plane/docs/implementation-plan.md` (application shell,
navigation, the S3 list/create/delete pages, loading/empty/error states).

Vitest, Playwright — see the implementation plan's Section 5.1 for the full
rationale.
